# Toolr Gemini CLI Extension

Connect Toolr to Gemini CLI to query your field workforce 
directly from the terminal.

## Installation

```bash
gemini extensions install https://github.com/mergim-hub/toolr-gemini-extension
```

## Setup

```bash
gemini extensions config toolr
# Enter your Toolr Bearer token when prompted
```

You can find your Bearer token by logging into mytoolr.com.

## Example prompts

- "Who is clocked in right now?"
- "Who is overdue on safety training?"
- "Give me a summary of all crews"
- "Show me recent form submissions"
- "What jobs are currently assigned?"
- "How many hours did [employee] work this week?"

## Requirements

- Gemini CLI v0.28.0+
- A Toolr account (mytoolr.com)
